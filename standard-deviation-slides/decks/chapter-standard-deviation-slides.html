  • In particular, \mathop{\mathrm{E}}[1_{\ge t}(X)]=P(X\ge t).

Markov’s Inequality

  • For X\ge0 and t>0, how large can P(X\ge t) be? \begin{aligned} P(X\ge t) &\class{fragment=0}{\overset{\texttip{\small{\text{?}}}{probability as expectation}}{=}\mathop{\mathrm{E}}[1_{\ge t}(X)]}\\ &\class{fragment=1}{\overset{\texttip{\small{\text{?}}}{the ramp bounds the indicator}}{\le}\mathop{\mathrm{E}}\sb*{\frac Xt}}\\ &\class{fragment=2}{\overset{\texttip{\small{\text{?}}}{linearity}}{=}\frac{\mathop{\mathrm{E}}[X]}t.} \end{aligned}

A Hint for Chebyshev’s Inequality

  • Let Z=X-\mathop{\mathrm{E}}[X].
  • How can we use Markov to bound P(|Z|\ge t)?
  • Fold the left mass onto the right.
  • Keep both contributions in the stack.
  • Squaring moves the cutoff from t to t^2.
  • The events |Z|\ge t and Z^2\ge t^2 select exactly the same observations.

Chebyshev’s Inequality: Your Turn

Figure 13

  • For a random variable X with finite variance and t>0, prove P(|X-\mathop{\mathrm{E}}[X]|\ge t)\le\frac{\mathop{\mathrm{\mathop{\mathrm{V}}}}[X]}{t^2}.

Chebyshev’s Inequality: Visual Solution

  • Write Z=X-\mathop{\mathrm{E}}[X].
  • For t>0, \begin{aligned} P(Z\le-t\text{ or }Z\ge t) &\class{fragment=0}{=P(|Z|\ge t)}\\ &\class{fragment=1}{=P(Z^2\ge t^2)}\\ &\class{fragment=2}{=\mathop{\mathrm{E}}[1_{\ge t^2}(Z^2)]}\\ &\class{fragment=3}{\le\mathop{\mathrm{E}}\sb*{\frac{Z^2}{t^2}}}\\ &\class{fragment=4}{=\frac{\mathop{\mathrm{E}}[Z^2]}{t^2}=\frac{\mathop{\mathrm{\mathop{\mathrm{V}}}}[X]}{t^2}.} \end{aligned}

The Standard Deviation is Standard

  • Write \sigma=\mathop{\mathrm{sd}}(X).
  • If \sigma>0, then for every k>0, Chebyshev’s inequality says P(|X-\mathop{\mathrm{E}}X|\ge k\sigma)\le \frac1{k^2}.
  • If \sigma=0, then X=\mathop{\mathrm{E}}X with probability one, so there is no positive departure from the mean to bound.
  • The statement contains no density, no named distribution, and no approximation.
  • Two standard deviations means a tail probability no larger than 1/4 for every distribution with finite variance.
  • Four standard deviations means no larger than 1/16.
  • The exact tail probability changes from one distribution to another; the guarantee does not.

Exercise 1  

  • Let \hat\theta be an unbiased estimator of \theta with standard deviation \sigma.
  • By applying Markov’s inequality to |\hat\theta-\theta|^2, find a lower bound on P(|\hat\theta-\theta| \le t\sigma) as a function of t.
  • For what choice of t is this bound equal to .95?
  • Explain how you can use this to get an interval estimate \hat\theta \pm t\sigma with a coverage probability of at least 95%.
  • If you have an upper bound on P(X > \epsilon), then you have a lower bound on P(X \le \epsilon). P(X \le \epsilon)=1-P(X > \epsilon) because X > \epsilon if and only if it is not the case that X \le \epsilon, so if P(X > \epsilon) \le u, then P(X \le \epsilon) = 1-P(X > \epsilon) \ge 1-u.
  • And if you’re troubled that Markov’s inequality says \ge instead of >, don’t be.
  • You have a bound on P(X > \epsilon) too. P(X > \epsilon) \le P(X\ge \epsilon) because X \ge \epsilon whenever X > \epsilon.

Bounding the Error

Solution

  • For t>0 and \sigma>0, apply Markov’s inequality to |\hat\theta-\theta|^2, which has mean-square \sigma^2 because \hat\theta is unbiased:

P(|\hat\theta-\theta|^2 \ge (t\sigma)^2) \le \frac{\mathop{\mathrm{E}}[(\hat\theta-\theta)^2]}{(t\sigma)^2} = \frac{\sigma^2}{(t\sigma)^2} = \frac{1}{t^2}. - The probability that |\hat\theta-\theta| > t\sigma is also no larger than 1/t^2 because this happens only if |\hat\theta-\theta|^2 \ge (t\sigma)^2. - And it follows that the probability that |\hat\theta-\theta| \le t\sigma is at least 1-1/t^2.

Solution

  • To find the value of t that makes this lower bound equal to .95, we solve 1-1/t^2=.95 to find t=\sqrt{1/(1-.95)}= \sqrt{20} \approx 4.5.
  • And because \theta \in [\hat\theta - t\sigma, \hat\theta + t\sigma] if (and only if) |\hat\theta-\theta| \le t\sigma, it follows that this interval has a coverage probability of at least .95.
  • If \sigma=0, unbiasedness implies \hat\theta=\theta with probability one.

Without Replacement: Exact and Guaranteed

Code 
# Model parameters (explicit; change them here). Hypergeometric population
# m chosen so its proportion matches theta (m*theta must be an integer
# count); FPC = (m-n)/(m-1) enters its actual variance.
intcomp.n = 625
intcomp.theta = 0.7
intcomp.m = 2000
intcomp.samples.binom = with_seed(
  rbinom(10000, intcomp.n, intcomp.theta)/intcomp.n)
intcomp.samples.hyper = with_seed(
  rhyper(10000, intcomp.m*intcomp.theta,
         intcomp.m*(1-intcomp.theta), intcomp.n)/intcomp.n)
# Actual PMFs and true SDs.
intcomp.pmf.binom = dbinom(0:intcomp.n, intcomp.n, intcomp.theta)
intcomp.pmf.hyper = dhyper(0:intcomp.n, intcomp.m*intcomp.theta,
                           intcomp.m*(1-intcomp.theta), intcomp.n)
intcomp.sigma.binom = sqrt(intcomp.theta*(1-intcomp.theta)/intcomp.n)
intcomp.sigma.hyper =
  sqrt(intcomp.theta*(1-intcomp.theta)/intcomp.n *
       (intcomp.m-intcomp.n)/(intcomp.m-1))
# Exact central-95 half-widths from SHARED width_binom/width_hyper only.
intcomp.hw.exact.binom = width_binom(intcomp.theta, intcomp.n)/2
intcomp.hw.exact.hyper = width_hyper(intcomp.theta, intcomp.n, intcomp.m)/2
# Chebyshev 95% half-widths: 1/t^2 = .05 gives t = sqrt(20); each estimator
# uses its ACTUAL true model sigma, never a sample plug-in.
intcomp.hw.cheb.binom = sqrt(20)*intcomp.sigma.binom
intcomp.hw.cheb.hyper = sqrt(20)*intcomp.sigma.hyper
# Measured integer-support coverage of those widths (measurement only: sums
# the pmf over counts inside each interval; finds no widths).
intcomp.measured.coverage = function(pmf, hw) {
  k = 0:intcomp.n
  inside = k >= ceiling(intcomp.n*(intcomp.theta - hw)) &
           k <= floor(intcomp.n*(intcomp.theta + hw))
  sum(pmf[inside])
}
intcomp.cov.exact.binom = intcomp.measured.coverage(intcomp.pmf.binom,
                                                    intcomp.hw.exact.binom)
intcomp.cov.exact.hyper = intcomp.measured.coverage(intcomp.pmf.hyper,
                                                    intcomp.hw.exact.hyper)
intcomp.cov.cheb.binom = intcomp.measured.coverage(intcomp.pmf.binom,
                                                   intcomp.hw.cheb.binom)
intcomp.cov.cheb.hyper = intcomp.measured.coverage(intcomp.pmf.hyper,
                                                   intcomp.hw.cheb.hyper)
